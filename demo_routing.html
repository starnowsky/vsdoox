📊 Адаптивные константы

Система теперь использует адаптивные значения на основе расстояния между объектами:

// Константы расстояния для адаптивной толщины линий (в пикселях) export const MIN_CONN_DIST = 30; // Минимальное расстояние (толщина 1px) export const MID_CONN_DIST = 120; // Среднее расстояние (интерполяция) export const MAX_CONN_DIST = 300; // Максимальное расстояние (толщина 2px) // Константа толщины линии (в пикселях) - используется для зазора между параллельными линиями и радиуса мостиков export const LINE_WIDTH = 2; // Значение по умолчанию

🔧 Адаптивная функция толщины линии

Функция `getLineWidthForConnection()` автоматически вычисляет толщину линии на основе расстояния:

export function getLineWidthForConnection(source: Pt, target: Pt): number { const dx = target.x - source.x; const dy = target.y - source.y; const distance = Math.sqrt(dx * dx + dy * dy); if (distance <= MIN_CONN_DIST) { return 1; // Толщина 1px при близком расположении узлов } else if (distance >= MAX_CONN_DIST) { return 2; // Толщина 2px при удалении } else { // Интерполяция между 1 и 2px в зависимости от расстояния const normalizedDist = (distance - MIN_CONN_DIST) / (MAX_CONN_DIST - MIN_CONN_DIST); return 1 + normalizedDist; // Возвращает значение между 1 и 2 } }
